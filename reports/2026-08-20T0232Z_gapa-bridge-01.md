## Stops and clarifications

### `S-1` — `OBSERVATION_METHOD_ERROR`, mine, caught before the result was recorded

**The first symbolic run reported `D1` and `D2` disagreeing.** `D1` returned
`[True, False, True, True, True]` for "each recipe fixed by `P2`" — the second
recipe, `(h11 + h22 − 2h33)/√6`, apparently not in `Im(P2)` — while `D2`
returned a projector difference of `4.228e-16` and subspace equality.

**§3 of the specification says a `D1`/`D2` disagreement is a result to report,
not a discrepancy to resolve by preferring one, and that the outcome is then
`INDETERMINATE`.** Applying that rule literally to the first run would have
returned `INDETERMINATE`.

**It was diagnosed first, and the cause was in my code.** The symbolic path fed
`sympy` the recipe vectors converted from `numpy` floats via
`nsimplify(..., rational=False)`, which leaves them as floats. The residual
`P2·v − v` was then

    [0, 0, 0, 0, −5.551115123125783e-17, 0, 0, −5.551115123125783e-17, 0,
     1.1102230246251565e-16]

and an exact symbolic comparison against `zeros(10,1)` reads that as "not
zero". **`1/√6` as a float is not `1/√6`.** The other four recipes survived only
because their entries — `1/√2` and `0` — happen to round without residue in
this construction.

**The repair, and why it is a repair and not a preference.** The exact-radical
tables `TT_RECIPES_EXACT` and `DISCARDED_EXACT` were added and the symbolic path
fed from those. **They are verified against the float tables in the script
itself** — `max|diff| = 2.220e-16`, printed in the output — so the symbolic
transcription is checked against the source values rather than asserted. With
exact radicals `D1` returns `True` for all five, and additionally returns exact
annihilation of all five discarded components.

**This is not `D1` and `D2` disagreeing about the repository.** It is one
implementation of `D1` being wrong about `D1`. **`INDETERMINATE` under §3 is
for a disagreement between two correct methods**, and returning it here would
have recorded a fact about my float handling as a fact about the two
projector bases.

**Recorded in full because the alternative was invisible.** A single run and a
literal reading of §3 would have produced a defensible-looking `INDETERMINATE`
that was simply wrong, and nothing in the specification's checks would have
caught it. **The thing that caught it was the size of the residual** — `5.6e-17`
is machine epsilon, not a structural failure — and that is the check worth
carrying forward: an exact symbolic comparison that fails by machine epsilon
has a float in it.
