## Stops and clarifications

**No stop occurred.**

### `S-1` — the windows were read from a module deliberately not imported

**Not a stop; a method choice recorded because it cuts against convenience.**

The two mass windows are defined in `scripts/recovered_2026/reproduce_betav.py`
at `:62-63`. **That module also carries an analytic reproduction target and a
drift figure.** Importing it to obtain the windows would have loaded both into
the process.

**The values were therefore read and cited as literals**, and the module is
never imported — the script says so in its own docstring. **The cost is that
the two `linspace` calls are transcribed rather than referenced**, which is a
transcription this task otherwise avoids everywhere. Mitigated by citing the
defining lines and by the values being reproduced in the pre-registration
before any result existed, so a mis-transcription would be visible against the
source rather than hidden in a computation.

### `S-2` — a third mass window exists, and reading "both" required a judgement

**Not a stop.** §1.3 says "BOTH of the windows the landed pipeline defines".
**The pipeline defines three:** `paper_win`, `light`, `heavy`. The vector path
uses `light` and `heavy`; `paper_win` is consumed only by the scalar `β_B`
path.

**"Both" was read as the two the vector path uses**, on the ground that
§0d.1 forbids computing `β_B` and `paper_win` is that computation's window.
**The alternative reading — that `paper_win` and one other are meant — would
have required computing on a window whose only landed use is the forbidden
one.** The judgement is recorded here and in the artifact's PART 1 §1.3 rather
than silently resolved, and the three windows are named so the Researcher can
overrule it.

### `S-3` — two acceptance checks reported false negatives, for two different reasons

**Not a stop; both were my verification, not the artifact, and both were
caught.**

`C14`'s fourth named item reported `MISSING`. The artifact reads
`` **`H-EXT-01` IS UNRESOLVED, IN EITHER DIRECTION.** `` — **with backticks**,
which the probe's whitespace normalisation did not strip.

`C10` reported no match for `THE PREDICTION HELD`. The artifact carries it
**across a line break**, between `THE` and `PREDICTION`.

    before   C14 3 of 4 present, C10 absent
    after    C14 4 of 4 present, C10 present

**Both pass under one normalisation applied to both sides — code delimiters
stripped, whitespace collapsed across line breaks.**

**Category: `OBSERVATION_METHOD_ERROR`, and this is the third occurrence in
this session's line of work.** The line-break case is the defect class this
repository has recorded before. **The backtick case is a variant of it that
the recorded lesson does not name**: normalising whitespace is not enough when
the target text is marked up. **Had either false negative been reported rather
than diagnosed, it would have read as a required statement missing from the
artifact.**

### `S-4` — the prediction held, and what that does not license

**Not a stop; recorded because a held prediction is the easier case to
over-read.** Both ratios have a smaller relative spread than either aggregate —
`1.13` and `1.50` against `3.44` and `3.85`.

**The Reviewer's §12 warns that observed relative spread alone should not be
promoted into a causal claim about cancelling systematics.** It is not
promoted. The artifact states the prediction held and that it is *consistent

### `S-5` — `B_R` changes sign between the windows

**Not a stop, and not an error. A measurement.**

Every `β_i` and both aggregates are positive on the heavy window and negative
on the light one. **The retained aggregate's spread therefore exceeds either

is visible rather than hidden behind a ratio that looks stable.

**No explanation is offered and none is authorised.** It is recorded in the
artifact's §12 and again as an open question in §19, where the question — which
window is the right one to read, and on what target-free ground — is left
undecided because the repository holds no criterion for deciding it.
