reviewed result did not carry.

## 3. Abort conditions

    A1  Any M1 value disagrees with this spec's Base, Source, or
        stated merge-base. STOP before any write; report the
        measured values. (A moved main is stale-base handling per
        BRANCHING_POLICY.md, not an error to repair silently.)
    A2  The merge is not conflict-free, or M3 finds any digest
        mismatch in the merge product. STOP; report the conflict or
        the measured digest; do not resolve content inside this
        task.
    A3  Advancing main would not be a fast-forward at push time.
        STOP; report; stale-base handling applies.
    A4  Any step would require modifying the source branch or any
        file arriving from it. STOP; report.
    A5  M3b finds: a contributed path outside the authorized
        manifest, or a non-A status, in either case with no
        exception; a path in the both-changed class; or any
        source-unchanged path whose merge-product blob differs from
        the Base's blob, or any main-unchanged contributed path
        whose merge-product blob differs from the source's blob.
        STOP; report the path and all applicable blob ids — for a
        source-only or main-only hazard: fork, the changed side, and
        product; for a both-changed path: fork, source, Base, AND
        product, all four — so the report shows how each side moved
        from the fork and which content the merge selected. Do not
        repair the merge inside this task.
