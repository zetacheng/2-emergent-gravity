### 4a. Push scope — and one observation returned to the PI

The clause as landed names **the integration branch and `refs/heads/main`**.
This task pushes those and no other ref.

**Observation, not a proposal.** The `P2-BRANCHING-SCIENCE-01` execution
pushed three refs: `main`, its integration branch, and the task branch
carrying its spec and review. The clause names two. The third was harmless —
no rewrite, and the ref was already an ancestor of the integration branch —

state, so pushing the task branch separately is not required for

Whether the clause should name the task branch is a policy question. **It is
not decided here, and this task does not push that ref.** If the executor
finds that conforming strictly makes some required artifact unreachable, that
is an `A4` return, not a workaround.

### 5.3 The load-bearing finding

`N_both = 0`: no milestone component holds both an applicable implementation
and a specification. Recorded with its consequence — the construction layer
itself is not established, which is why the primary verdict is a construction
verdict and not a ruling verdict.

### 5.4 Dependency transfer — two kinds, kept distinct

    POLE milestone    inherits R4 UNCONDITIONALLY. Its object is
                      <T_{mu nu}(x) T_{rho sigma}(y)>. The expectation-value
                      bracket enters the DEFINITION of the correlator, not
                      only the operator; without an ensemble / state space /
                      functional measure the correlator is not yet defined.

    SRC-B0            inherits CONDITIONALLY. A Gamma-defined stress tensor
                      inherits; an S-defined one does not; which the
                      programme needs is unresolved.

These appear as separate statements. Merging them loses the finding.

### 5.5 Negative delimitation of existing machinery

1. Barnes–Rivers projector machinery provides channel decomposition. It is not
   an interacting correlator, not pole extraction, not residue analysis.
2. `tt_check.py` computes four channels and the caller retains the first.
   Recorded as evidence that building blocks present is not milestone
   implementation present.
3. RECON-01a establishes a curved bosonic determinant / operator construction.
   Metric variations of `logdet` yield an effective-action response, a
   Γ⁽²⁾-class object. It is **not** an interacting stress-tensor correlator
   and is not to be renamed as one.

The POLE-B0 report at `3f78acfe` states, of scipy, that the manifest declares
